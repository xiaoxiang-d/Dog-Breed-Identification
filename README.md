# 犬种鉴定实验记录

## 1. 实验目标

基于 Stanford Dogs 数据集，使用卷积神经网络实现 120 种犬种的图像分类，并按照官方测试集划分评估模型准确率。

## 2. 数据集

- 数据集：Stanford Dogs
- 犬种数量：120
- 官方训练集：12,000 张
- 实际训练集：9,600 张
- 验证集：2,400 张
- 官方测试集：8,580 张
- 划分方法：官方训练集内部按类别分层随机划分，随机种子为 42

## 3. 模型与训练配置

- 网络结构：ResNet18
- 训练方法：迁移学习
- 预训练参数：冻结
- 分类层：512 → 120
- 优化器：Adam
- 学习率：0.001
- 损失函数：交叉熵损失
- 批次大小：32
- 训练轮数：5
- 计算设备：NVIDIA GeForce RTX 5060 Ti

## 4. 实验结果

| 指标 | 结果 |
|---|---:|
| 最后一轮训练损失 | 0.4777 |
| 验证集准确率 | 75.88% |
| 官方测试集准确率 | 76.71% |
| 测试图片数量 | 8,580 |
| 正确分类数量 | 6,582 |
| 错误分类数量 | 1,998 |

## 5. 初步分析

训练损失随训练轮次增加而下降，说明模型逐渐拟合训练数据。

验证集准确率为 75.88%，官方测试集准确率为 76.71%，两者相差 0.83 个百分点。

由于目前缺少逐轮验证损失和准确率记录，尚不能确定是否存在明显过拟合。

本次结果来自保存的最后一轮模型，未进行最佳轮次筛选。
